🎮 Proyecto RP – Servidor de Roleplay GTA V

Diseño y desarrollo integral de un servidor de roleplay en GTA V utilizando la plataforma FiveM. Incluye scripts personalizados en Lua para mecánicas de juego, sistema de economía virtual, gestión de base de datos con persistencia de personajes, sistema de moderación y documentación técnica completa para la comunidad. Diseño gráfico del branding del servidor realizado en Adobe Photoshop. Optimizado para alto rendimiento con múltiples jugadores simultáneos.

📊 Live Tracker – Plataforma de Análisis para TikTok Live

Aplicación web progresiva (PWA) para rastreo y análisis de sesiones de TikTok Live. Cuenta con registro de sesiones con conversión USD-COP en tiempo real, dashboard de estadísticas con gráficas interactivas, sistema de metas semanales, módulo de análisis con insights personalizados, y un IA Coach integrado con inteligencia artificial que brinda retroalimentación y recomendaciones basadas en los datos del streamer. Backend con Supabase y desplegado en Netlify.

HTML5CSS3JavaScriptSupabase API de IAPWANetlify

🔊 Soundboard – Tablero de Sonidos para Streaming

Aplicación de escritorio desarrollada con Electron para reproducir efectos de sonido durante transmisiones en vivo. Cuenta con atajos de teclado globales configurables, control de volumen individual por sonido, almacenamiento persistente de la biblioteca de sonidos, y una ventana de audio oculta dedicada que garantiza la reproducción confiable incluso cuando la aplicación está minimizada. Diseñada para ser utilizada en streams de TikTok Live.
